# ReGrade

AI-powered recommerce marketplace for used consumer electronics in India.

## Tech Stack
- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL (via Supabase)
- **Auth:** Supabase Auth
- **Payments:** Razorpay (Test Mode)
- **AI/ML:** Replaceable Service Adapters (Roboflow / YOLO + Heuristics)

# 3. Run linter
npm run lint

npm run build
